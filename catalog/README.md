# catalog/

Versioned, offline JSON content catalogs live here (added per phase):

- one JSON file per content domain (`library.json`, `manuals.json`, …),
- every item records `license`, `source_url` and a verification status
  (see `docs/CONTENT_SOURCES.md` for policy),
- URLs that have not been re-checked are marked `UNVERIFIED`.

Phase 0 ships no catalogs yet.
